- (decision) PrintCost is an offline-capable single-user PWA for 3D print cost calculation; MVP has no backend, accounts, cloud sync, or team features.
- (decision) The PRD and implementation contract must be in English, including data models, service names, field names, enums, stores, and public labels used as implementation guidance.
- (decision) All user data is stored locally in browser IndexedDB; JSON export/import is the MVP backup strategy and import replaces existing local data.
- (decision) The PRD and implementation identifiers stay English, but the application UI itself is German: navigation labels, form labels, validation messages, onboarding, toasts, dialogs, and user-facing content.
- (override) Clarification supersedes the earlier public-label wording: public/user-facing labels are German; English applies only to implementation identifiers and internal contracts.
