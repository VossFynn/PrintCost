## Extracted Into DESIGN.md

- Warm cream board and app surfaces: `#EFE7DC`, `#FAF7F2`, `#FFFFFF`.
- Terracotta primary accent: `#C4622D`.
- Slate primary text: `#2C3E50`.
- Muted taupe labels and borders: `#A99C88`, `#9B8F7D`, `#ECE3D5`, `#F2ECE1`.
- DM Sans typography, compact mobile scale, no display serif.
- Soft rounded controls and cards: 10-18 px, full radius for chips/swatches.
- Subtle shadows for cards, result panel, phone frame, and floating action.
- Fine-line icon style and content-colored Filament swatches.

## Gaps or Conflicts

- Wireframe shows `CSV - Backup`, while the PRD places CSV export after MVP. EXPERIENCE.md keeps this as an open UX item.
- Wireframe is mobile-only. EXPERIENCE.md defines responsive behavior but marks desktop layout as an open item.
- Wireframe is static and does not define validation, empty states, backup confirmation, or data deletion behavior; EXPERIENCE.md derives those from the PRD.
