- (direction) Express distill from PRD, UX design folder, and architecture spine; user supplied all inputs and slug derived as printcost.
- (capability) CAP-1 Price a print job: user can enter project, printer, customer, filaments, grams, minutes, quantities, model state, profit, and extra-work fee to see live rounded EUR price within 100 ms.
- (capability) CAP-2 Manage printer profiles: user can create, edit, select, and soft-delete printer cost profiles while saved calculations keep historical printer snapshots.
- (capability) CAP-3 Manage filament inventory: user can track filament metadata, purchases, colors, remaining grams, price modes, weighted/paid/fixed price basis, and soft-deleted historical references.
- (capability) CAP-4 Save and reuse calculations: user can save planned or completed calculation records with snapshots and computed outputs, load templates, and keep records stable after source edits.
- (capability) CAP-5 Track printed inventory and sales: user can view saved calculations in Bestand > Drucke, record print occurrences with stock deduction, record sales/gifts, and manage manual Teile separately.
- (capability) CAP-6 Manage customers: user can create, edit, soft-delete, and select optional local customer records for calculations and sales.
- (capability) CAP-7 Manage defaults and settings: user can set calculation defaults, export/import data, delete all local data with confirmation, and handle service-worker update prompts.
- (capability) CAP-8 Backup and restore: user can export all local data as versioned JSON and import a validated replace-all backup without backend or account.
- (capability) CAP-9 Install and use offline: user can install the PWA and complete calculation, inventory, filament, customer, settings, template, export, and import workflows offline after first load.
- (constraint) MVP is local-only offline-capable PWA: no backend, accounts, cloud sync, analytics, external runtime fonts/dependencies, invoicing, tax, ERP, telemetry integrations, push notifications, photo attachments, resin-specific workflow, or automatic scale measurement.
- (constraint) User-facing UI and accessibility copy is German; implementation identifiers, routes, models, services, store names, enum values, tests, backup fields, and internal docs are English; formatting uses de-DE EUR conventions.
- (constraint) Calculation contract follows architecture AD-4: printMinutes and gramsUsed are total job inputs; plate count never multiplies material or time costs; use extraWorkFeePercent and not multiPlateSurchargePercent.
- (constraint) Stock contract follows architecture AD-5/AD-6: saving a calculation never deducts filament; explicit print occurrence deducts total gramsUsed from current filament stock; sales never deduct filament; low stock clamps to zero with German warning; missing filament blocks command.
- (constraint) Architecture companion is binding for implementation: Angular 22 feature-sliced layered PWA, service-owned Signals/mutations, IndexedDB via core/db only, GitHub Pages static hosting, strict CSP, lazy feature routes, unit-tested pure calculation.
- (decision) Adopted companions: DESIGN.md, EXPERIENCE.md, ARCHITECTURE-SPINE.md, IMPLEMENTATION-HANDOFF.md; spec-authored companion domain-contract.md preserves PRD data, formula, validation, route, and backup details.
